# Destrava Conversas

Página inicial de **destrava-conversas.com.br**. O endereço antigo, `destrava-conversas.github.io`, redireciona para cá.

- **Conversas públicas** (abertas): cada projeto mora no seu próprio repositório e aparece em `/nome-do-projeto/`.
  - [Painel Observatório da Direita Radical e Extrema](https://destrava-conversas.com.br/observatoriodireitaradical/) — repositório `observatoriodireitaradical`
  - [E a Economia?](https://destrava-conversas.com.br/observatoriodireitaradical/economia/)
- **Área das turmas** (com senha): os decks ficam no Cloudflare Pages (`ad-decks.pages.dev`, repositório privado `decks`). O botão "Entrar com a senha da turma" abre `ad-decks.pages.dev/turmas/`, que leva cada senha à página da sua turma.

Imagens em `assets/` (logo, ícone e foto).
